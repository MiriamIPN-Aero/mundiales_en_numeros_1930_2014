# Mundiales en Números 1930-2014
Dashboard interactivo hecho 100% en Excel

Proyecto personal para practicar análisis de datos. Analicé 20 mundiales (1930-2014) con datos de Kaggle.

### ¿Qué hice?
- Limpieza con Power Query (unión de tablas, limpieza de nulos, tabla calendario)
- Modelado con Power Pivot y relaciones
- Medidas DAX: total mundiales, partidos, equipos, goles, asistencia, promedio de goles por mundial
- Dashboard con segmentadores por año y sede

### Stack
Excel | Power Query | Power Pivot | DAX | Tablas Dinámicas

### Archivos
- `mundial-1930-2014.xlsx` - Archivo con modelo y dashboard
- `dashboard.png` - Captura del dashboard

Fuente: Kaggle - World Cup Dataset 1930-2014 (con limpieza adicional)
